# IU Brain — verified public-statement corpus

이 폴더는 아이유(IU/이지은)의 **공개 인터뷰·공식 발언을 근거로 한 사고 관찰치**를 저장한다.
목표는 말투 복제가 아니라, 여러 시기의 공개 자료에서 반복되거나 변화하는 판단 방식을 추적해 `나의 바다` 조언 엔진이 근거 검색에 사용하도록 하는 것이다.

## 원칙

- 실제 아이유 본인인 척하지 않는다.
- 사적 심리·임상진단·숨은 의도를 추측하지 않는다.
- 한 발언을 영구적 성격으로 일반화하지 않는다.
- 서로 다른 시기의 발언이 충돌하면 둘 다 보존하고 변화 또는 양가성으로 다룬다.
- 원문은 `quote`에 짧게만 보관하고, 핵심은 `observation`으로 상세 요약한다.
- 기사 재인용보다 원 인터뷰·공식 영상·공식 매체를 우선한다.
- 노래 가사와 작품 해석은 직접 심리 근거와 분리한다.

## Evidence tier

- `A++` — 공식/주요 매체의 원 인터뷰, 아이유가 직접 말한 원 출처
- `A+` — 공식 방송·수상소감·콘서트·공식 비하인드의 직접 발언
- `A` — 신뢰도 높은 장문 보도에서 확인되는 직접 발언
- `B` — 신뢰도 높은 2차 보도/전사
- `C` — 팬 업로드·재전사 등 보조 자료. 반드시 교차검증 후 사용
- `D` — 가사·작품·연구자의 해석. 조언의 직접 근거로 단독 사용하지 않음

## Record schema

각 줄은 JSON object다.

- `id`
- `year`
- `source`
- `publisher`
- `url`
- `tier`
- `topics[]`
- `observation` — 원문을 길게 복제하지 않은 검증 요약
- `quote` — 매우 짧은 근거 문구

## Advice retrieval

`backend/main.py`는 사용자의 고민과 최근 `나의 바다` 기록에서 주제를 추출하고, `verified_observations.jsonl`에서 관련 관찰치를 검색한다. 상위 근거를 시간축으로 겹쳐 GPT-5.6에 전달한다.

조언 생성 시:

1. 현재 감정과 사실/해석을 구분한다.
2. 여러 연도의 공통점과 변화점을 비교한다.
3. 아이유 공개자료가 뒷받침하지 않는 내용은 아이유의 생각처럼 단정하지 않는다.
4. 답변에 사용한 실제 근거 목록을 프론트엔드에 반환한다.

## 현재 연구 방향

우선순위는 다음과 같다.

1. 2010–2014 초기 인터뷰: 자기보호, 인기, 실패, 관계 거리두기
2. 2015–2019: 공허함, 감정 회피, 창작, 25세 전후 자기이해 변화
3. 2020–2022: 자기애/자존감 구분, 사랑 받기, 결과 귀인, 30대 전환
4. 2023–2026: 자기 기준, 사랑/관계, 유연성, 삶의 지속성, 자기관대함
5. IU TV / Palette / 방송 / 라디오 / 수상소감의 직접 발언을 별도 검증해 추가

이 corpus는 양보다 **중복 제거·맥락·시간축·반대 증거 보존**을 우선한다.
