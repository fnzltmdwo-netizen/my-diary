# IU Brain Corpus

목표: 아이유가 공개적으로 한 발언을 가능한 한 많이 수집해, 출처·시점·맥락·사고원칙 단위로 검색 가능한 데이터셋으로 만든다.

## 원칙
- 원문 전체를 저장하지 않는다. 영상/기사 전체 자막은 수집 과정에서만 임시로 사용하고 최종 저장물에는 남기지 않는다.
- 최종 저장은 `출처 URL + 타임스탬프 + 25단어 이하의 짧은 인용(선택) + 상세 요약 + 사고원칙 + 태그` 중심으로 한다.
- 직접 발언과 해석을 분리한다.
- 실제 아이유의 사적 심리·진단을 추정하지 않는다.
- 같은 발언이 재업로드/기사화된 경우 원본을 우선한다.

## 증거등급
- A++: 아이유 공식 채널/방송사/언론사 원본 영상에서 아이유 본인이 직접 말함
- A+: 아이유 장문 원문 인터뷰, 공식 기자간담회/수상소감
- A: 공식 콘서트/비하인드/라이브에서 직접 발언
- B: 신뢰할 만한 기사·전문·2차 보도에서 직접 발언을 확인 가능
- C: 팬 업로드·재업로드·2차 자막/전사
- D: 작품/가사/연구자의 해석. 실제 심리의 직접 증거로 사용하지 않음

## 수집 영역
1. 이지금 [IU Official] 전체 영상
2. 아이유의 팔레트 전편
3. IU TV / Homebody Signal / 앨범 메이킹 / 콘서트 비하인드
4. 방송사 공식 채널: tvN, JTBC, KBS, SBS, MBC, Mnet 등
5. 시상식·수상소감·콘서트 멘트
6. 국내외 언론 영상 인터뷰: Billboard, GQ, W, Vogue, ELLE, Harper's Bazaar, Marie Claire 등
7. 장문 기사 인터뷰와 공식 웹문서
8. 학술논문·비평은 별도 보조 코퍼스로 저장

## 핵심 태그
자기애, 자기수용, 자기비판, 경계, 사람, 신뢰, 우정, 사랑, 팬, 가족, 일, 성공, 실패, 운, 비판, 악플, 명성, 불안, 공허함, 슬럼프, 슬픔, 상실, 분노, 외로움, 휴식, 야망, 완벽주의, 통제, 불확실성, 창작, 나이듦, 성장, 일기, 기억, 회복, 친절, 책임, 경쟁, 후회, 관계거리, 사랑받기, 자기관대함.

## 대규모 수집 방식
`collector.py`가 유튜브 채널/검색 결과를 열거하고 자막을 임시로 읽은 뒤, OpenAI Responses API로 '아이유 본인의 발언'만 원자 단위 관찰치로 추출한다. 원문 자막은 저장하지 않는다.
